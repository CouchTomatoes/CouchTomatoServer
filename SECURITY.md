# Security policy

## Supported versions

Only the latest release on `main` gets security fixes. Please update before reporting:
[latest release](https://github.com/CouchTomatoes/CouchTomatoServer/releases/latest).

## Reporting a problem

**Please don't open a public issue.** Report it privately through GitHub:
[Report a vulnerability](https://github.com/CouchTomatoes/CouchTomatoServer/security/advisories/new).

Include the version, how you run CouchTomato, and the steps that show the problem. You'll get
an answer within a week. Once a fix is released, the report is credited to you unless you'd
rather stay anonymous.

## Good to know

CouchTomato is meant to run on your own network. If you open it to the internet, set a
username and password (Settings → General) and put it behind HTTPS.
